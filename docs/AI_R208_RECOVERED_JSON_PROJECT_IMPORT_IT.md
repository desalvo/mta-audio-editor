# r208 - Recovered AI JSON project import

Native pending requests for Whisper and Chords can be applied with `POST /api/native/ai-workers/pending/{request_id}/import-json/{pid}`. Only pre-existing requests in the native journal are eligible, with the current worker credentials and endpoint validated by the read-only artifact recovery route. The importer handles either a standalone JSON result or a ZIP containing exactly one expected `transcript.json` / `chords.json` member, imposes bounded payload/event counts, parses events using the project Pydantic models, and saves both annotations and the provenance receipt (`recovered_ai_imports`) together under the project-wide publication lock. Replays return 409; manual annotations are not overwritten. The pending journal remains intact. The project must have empty corresponding annotations and event timestamps must already refer to the desired timeline origin; the importer does not infer audio source mapping. Other ZIP stem layouts are not supported. GPU billing remains disabled without trustworthy metering.
