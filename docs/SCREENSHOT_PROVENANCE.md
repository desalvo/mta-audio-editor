# Documentation screenshot provenance

The raster screenshots in `app/static/docs-assets/` are generated from the current MTA Audio Editor application template, JavaScript rendering code, CSS and a deterministic demo project. They are not crops of `app/static/mockup-reference.png`.

Current application screenshots:

- `daw-overview.png`
- `transport.png`
- `inspector.png`
- `timeline.png`
- `mixer.png`
- `export-panel.png`
- `plugin-editor.png`

SVG files in the same directory are explanatory diagrams, not screenshots. The photographic cover image is an illustrative project image, not a UI screenshot.
