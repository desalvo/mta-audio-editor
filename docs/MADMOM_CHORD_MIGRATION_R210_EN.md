# Chord migration r210 — English

Chord profiles select BTC-HCQT (only if installed and permitted by license policy), Chordino and MTA Chromagram. Automatic profiles no longer select Madmom; explicitly selected Madmom remains blocked for its noncommercial checkpoint weights. ChordFormer is not automatically enabled without verified rights for the exact checkpoints.

Balanced/Detailed modes retain extended chords, sus2/sus4, m7b5, dim7, add9, 9, maj9, m9, 7b5, 7#5, 7b9, 7#9; independent bass analysis may add slash bass and inversions. Stable retains simplified Songbook output. A broader vocabulary does not guarantee accuracy on real audio; annotated benchmark testing is still required.

UVR, DrumSep and other checkpoints with unresolved rights remain blocked. No-charge operation, external downloads or operator attestations do not by themselves grant rights. CPU/GPU metering remains intact.
