Modelli UVR preesistenti conservati come legacy. Aggiunti test sintetici di contratto, senza benchmark reale. Nessun checkpoint incluso o scaricato automaticamente. Consultare `docs/MVSEP_MEGA53_LEAD_BACKING_R210_IT_EN.md`.

Prior UVR models are retained as legacy. Synthetic contract tests were added; no real musical benchmark is claimed. No checkpoint bundled or automatically fetched. See `docs/MVSEP_MEGA53_LEAD_BACKING_R210_IT_EN.md`.
