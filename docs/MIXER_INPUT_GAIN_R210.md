# Mixer input gain — 0.3.0-r210

Each track mixer strip now includes an independent rotary Gain trim above Pan. It provides a numeric dB field, a -24 to +24 dB range in 0.1 dB increments, horizontal/upward pointer dragging, double-click reset to 0 dB, arrow keys (Shift for 1 dB steps), Home/End for limits and 0 for unity. The slider exposes its current value and unit through accessibility attributes. Keyboard events on the knob do not move selected timeline segments. The compact Gain row fits the existing channel width, and the master spacer keeps the fader area aligned. The master retains its existing master fader; Gain is a track input control.

Gain is separate from the track volume fader and is applied before built-in and VST3 inserts. The validated Track.gain_db field defaults to 0 for old projects and rejects nonfinite/out-of-range API values. Project serialization persists it without altering the fader. Track, mix and MTA renders inherit the pre-insert gain from the shared renderer.

Dry playback applies trim live in WebAudio together with the track fader. With rendered inserts, trim is baked before the effects and is not applied again in the browser. Preview models are neutralized only for dry/no-insert audio; processed preview signatures include the gain value. Changing Gain invalidates decoded/warm caches and uses the existing live processed-track refresh path when insert audio needs regeneration. Rendered-master playback uses the existing master-refresh mechanism.
