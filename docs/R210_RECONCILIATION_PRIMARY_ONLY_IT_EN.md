# IT — Riconciliazione primaria
Nei confronti fra 3–4 trascrittori, gli eventi aggiunti dai modelli secondari non diventano automaticamente riferimento per i modelli successivi. Si confrontano solo le note della previsione primaria, mantenendo tutte le ipotesi secondarie come materiale da revisionare. Evita false concordanze; non misura la correttezza musicale. Test: 23 superati. Le macroaree Vocal Studio e Audio-to-MIDI restano aperte.

# EN — Primary-only reconciliation
For 3–4 transcriber hypotheses, secondary model events must not become reference anchors for subsequent models. Only original primary notes are matched. All secondary hypotheses are retained for manual review. This prevents spurious consensus, not a measure of musical accuracy. Tests: 23 passed. Full Vocal Studio and Audio-to-MIDI macroareas remain open.
