# Profilo MP3 Karaoke M-Live / Merish

MTA Audio Editor esporta un MP3 standard con tag ID3v2.3. Le lyrics sono salvate in SYLT content type 1 con fallback USLT, gli accordi in un SYLT content type 5 e i marker in SYLT content type 4. I timestamp SYLT sono espressi in millisecondi. Titolo, artista e autori sono salvati nei frame TIT2, TPE1 e TCOM.

Il profilo mantiene lo stream audio MP3 indipendente dai metadati karaoke. Il documento PDF generato in `app/docs/MTA-Audio-Editor-M-Live-Merish-MP3-Format-Specification-IT.pdf` costituisce la specifica completa del profilo implementato.
